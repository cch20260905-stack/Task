# DESIGN.md · LGMFormer 复现汇报（学术风）

> 命中预设风格：**学术风**（`design-principle.academic.md`）。本文件仅声明"结合本项目需求需要微调"的项，其余严格遵循该风格文件。

## 1. 画布与母版

- 画布 **1280×720**，安全边距左右 40。
- 页眉模式全篇锁定 **A3**（深蓝顶条 h=72 + 低透明线稿）：封面/目录/扉页/结束页省略 A/D，其余页遵守。
- 内容页三区：A 页眉 0–72 / B 内容 80–660 / C 页脚 660–700（左：论文复现 · 声呐鱼群计数；右：页码 NN/13）。

## 6. 页面微调声明

- 本项目为"无官方代码的自实现复现"，P5 需明确列出约束条件（仓库为空、超参缺失）——这是学术诚实性的关键，不属避讳内容。
- P12 的"缺口归因"用警示红强调三个障碍名称（多任务权衡 / 泛化 gap / 超参缺失），配深蓝原因说明——红仅用于标签，≤3%。
- 全篇禁：夸张营销词、虚构数据、伪造论文引用。
